# ملاحظات الإصلاح

## المشكلة 1: التبويبات المختفية
- في الرئيسية يظهر 7 تبويبات: ذكري، شبكتي، العائلة، الأسبوعي، الصلاة، الفطرة، الرئيسة
- عند الانتقال لشاشة الفطرة يظهر فقط 5: العائلة، الأسبوع، الصلاة، الفطرة، الرئيسية
- السبب: PersistentTabBar يحتوي فقط 5 تبويبات ويظهر خارج tabs
- لكن المشكلة الحقيقية: tabs/_layout.tsx يحتوي على 7 تبويبات مرئية (index, fitrah, prayer-times, weekly, family, messages, dhikri)
- "messages" = شبكتي، "dhikri" = ذكري
- يبدو أن الشاشات الخارجية (library, community, child) تستخدم PersistentTabBar الذي فيه 5 فقط
- الحل: تحديث PersistentTabBar ليحتوي كل 7 تبويبات

## المشكلة 2: أكواد Unicode في الويدجت
- الأزرار تظهر كـ \u2192 و \u21BB بدلاً من أيقونات
- السبب: الويدجت تستخدم FlexWidget وليس React Native components
- FlexWidget لا يدعم الأيقونات بنفس الطريقة
- الحل: استخدام نص عادي مثل ← → ↻ أو صور
