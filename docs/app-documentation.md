# وثيقة إمكانيات تطبيق "نصيحة" للتربية الإسلامية

**الإصدار:** 1.0  
**تاريخ التحديث:** 30 يونيو 2026  
**المنصات المدعومة:** iOS، Android، Web

---

## نظرة عامة

تطبيق "نصيحة" هو تطبيق شامل للتربية الإسلامية يهدف إلى مساعدة الآباء والأمهات في تربية أبنائهم وفق المنهج الإسلامي الصحيح. يقدم التطبيق نصائح يومية وأسبوعية مخصصة، ومستشاراً ذكياً يعمل بالذكاء الاصطناعي، وشبكة متخصصين من العلماء والمعلمين والأطباء، بالإضافة إلى أدوات متابعة تطور الأبناء.

---

## الأقسام الرئيسية

### 1. الصفحة الرئيسية (الشاشة الأولى)

الصفحة الرئيسية هي المحور المركزي للتطبيق، وتحتوي على العناصر التالية:

| العنصر | الوصف |
|--------|-------|
| **التاريخ الهجري والميلادي** | يعرض التاريخ الهجري الدقيق (المعتمد على حسابات فلكية) والتاريخ الميلادي |
| **أوقات الصلاة** | عرض وقت الصلاة التالية مع عداد تنازلي |
| **أزرار الأذكار** | أذكار الصباح والمساء وأذكار ما بعد الصلاة |
| **الإجراءات السريعة** | شبكة أزرار للوصول السريع لجميع أقسام التطبيق |
| **بطاقة النصيحة الشخصية** | نصيحة مخصصة بناءً على أحوال المستخدم وأسرته |
| **نصائح يومية** | رابط لصفحة النصائح اليومية مع إمكانية تأكيد التنفيذ |
| **اسأل سؤالاً** | رابط للمستشار الذكي |
| **اسأل متخصصاً** | رابط لشبكة المتخصصين |

#### 1.1 أوقات الصلاة

يحسب التطبيق أوقات الصلاة بدقة بناءً على موقع المستخدم الجغرافي، ويدعم عدة طرق حسابية:

- رابطة العالم الإسلامي
- الهيئة المصرية العامة للمساحة
- جامعة أم القرى
- الجمعية الإسلامية لأمريكا الشمالية (ISNA)
- معهد الجيوفيزياء بجامعة طهران

#### 1.2 الأذكار

يوفر التطبيق أذكاراً كاملة مقسمة إلى:
- أذكار الصباح
- أذكار المساء
- أذكار ما بعد الصلاة (مخصصة لكل صلاة)

---

### 2. صفحة العائلة (الأبناء)

تعرض هذه الصفحة بطاقات الأبناء المسجلين في شبكة عمودين (ابنان بجانب بعضهما)، وتحتوي على:

| الميزة | التفصيل |
|--------|---------|
| **بطاقة الابن** | تعرض اسم الابن وعمره بالسنوات والأشهر |
| **إضافة ابن جديد** | إمكانية إضافة أبناء جدد مع تحديد الاسم وتاريخ الميلاد والجنس |
| **حذف ابن** | إمكانية حذف ملف الابن |
| **تفاصيل الابن** | الضغط على بطاقة الابن يفتح صفحة تفصيلية |
| **النصائح الشخصية** | نصائح مخصصة لكل ابن بناءً على عمره وأحواله |
| **زر التحديث** | تحديث النصائح الشخصية من المستشار الذكي |

#### 2.1 النصائح الشخصية للأبناء

النصائح الشخصية تُولَّد بواسطة الذكاء الاصطناعي وتكون مخصصة لكل ابن بناءً على:
- عمر الابن
- جنس الابن
- البيئة التعليمية
- المشاكل المسجلة
- إجابات الوالد في الاستبيان

كل نصيحة تُعرض في قسم مطوي بعنوان خاص، ويمكن للمستخدم الضغط على العنوان لفتح تفاصيل النصيحة.

#### 2.2 تفاصيل الابن

صفحة تفصيلية لكل ابن تحتوي على:
- معلومات أساسية (الاسم، تاريخ الميلاد، الجنس)
- البيئة التعليمية (مدرسة، تعليم منزلي، أخرى)
- المشاكل والتحديات المسجلة
- خطة أسبوعية مخصصة
- إمكانية مشاركة بيانات الابن مع الشريك

---

### 3. الخطة الأسبوعية

تقدم خطة أسبوعية شاملة للأب تشمل:

| اليوم | المحتوى |
|-------|---------|
| **كل يوم** | مهام تربوية محددة مع إمكانية التأشير عند الإنجاز |
| **الجمعة** | مهام خاصة بيوم الجمعة (سورة الكهف، الصلاة على النبي) |
| **الاثنين والخميس** | تذكير بصيام السنة |

الخطة الأسبوعية تتضمن:
- نصائح تربوية يومية متجددة
- تذكيرات بالعبادات المستحبة
- أنشطة عائلية مقترحة
- متابعة الإنجاز بنسبة مئوية

---

### 4. النصائح اليومية (جديد)

صفحة مخصصة للنصائح اليومية مع إمكانية تأكيد التنفيذ:

| القسم | المحتوى |
|-------|---------|
| **شريط التقدم** | يعرض نسبة إنجاز النصائح اليومية بلون أحمر واضح |
| **نصائح إسلامية** | مبنية على اليوم الهجري والميلادي (صيام، أذكار، قرآن) |
| **نصائح تربوية** | 3 نصائح يومية متجددة (استمع لطفلك، امدحه، العب معه...) |
| **نصائح المكان** | مبنية على موقع المستخدم |
| **نصائح الموسم** | مبنية على الفصل الحالي |

كل نصيحة لها مربع تأكيد (checkbox) يضغط عليه المستخدم ليثبت أنه قام بتنفيذ النصيحة. يتم حفظ الإنجازات محلياً ويُعرض التقدم اليومي.

---

### 5. المستشار الذكي (AI Chat)

مستشار ذكي يعمل بالذكاء الاصطناعي متخصص في التربية الإسلامية:

| الميزة | التفصيل |
|--------|---------|
| **طرح الأسئلة** | يمكن للمستخدم كتابة أي سؤال تربوي |
| **أسئلة مقترحة** | أسئلة جاهزة يمكن الضغط عليها مباشرة |
| **إجابات مفصلة** | إجابات مبنية على المنهج الإسلامي مع أدلة |
| **سجل المحادثات** | حفظ المحادثات السابقة |
| **ملاحظات** | إمكانية حفظ ملاحظات من المحادثة |

المستشار الذكي يأخذ بعين الاعتبار:
- ملف الوالد الشخصي
- أعمار الأبناء وأحوالهم
- المشاكل المسجلة
- السياق الثقافي واللغوي

---

### 6. المفاهيم التربوية

قسم تعليمي يشرح المفاهيم الأساسية في التربية الإسلامية:

| المفهوم | الشرح |
|---------|-------|
| **التصفية** | تنقية النفس من الشوائب والأخلاق السيئة |
| **التزكية** | تنمية النفس بالأخلاق الحسنة والعبادات |
| **التربية** | تنشئة الأبناء على المنهج الصحيح |
| **الفطرة** | الطبيعة السليمة التي فطر الله الناس عليها |

كل مفهوم يُعرض بنص واضح خالٍ من الرموز، مع شرح مفصل وأدلة شرعية.

---

### 7. الفطرة

قسم خاص بمفهوم الفطرة في الإسلام وكيفية الحفاظ عليها في تربية الأبناء. يتضمن:
- شرح مفهوم الفطرة
- علامات سلامة الفطرة
- أسباب انحراف الفطرة
- طرق الحفاظ على الفطرة

---

### 8. العلاجات

قسم يتناول الأساليب العلاجية في التربية:
- علاج المشاكل السلوكية
- التعامل مع التحديات النفسية
- أساليب التقويم الإسلامية
- متى يجب اللجوء لمتخصص

---

### 9. شبكة المتخصصين (شبكتي)

نظام لإدارة شبكة المتخصصين المرتبطين بالمستخدم:

| الفئة | الوصف |
|-------|-------|
| **المعرّف** | ربط التطبيق بمعرّف شخصي عبر QR code |
| **الوالدان** | إضافة الشريك/الزوجة |
| **المعلمون** | معلمو الأبناء |
| **أهل العلم** | العلماء والمفتون |
| **الأطباء** | الأطباء والمعالجون |

#### 9.1 إضافة شخص جديد

تتم إضافة الأشخاص عبر إدخال **رقم الهوية فقط**:
1. يدخل المستخدم رقم هوية الشخص
2. يبحث التطبيق في الشبكة العامة
3. يعرض معلومات الشخص (الاسم، التخصص)
4. يضغط المستخدم "إضافة إلى شبكتي"

هذا النظام يضمن أن جميع المتخصصين المضافين مسجلون فعلياً في التطبيق.

---

### 10. أوقات الصلاة

صفحة مخصصة لأوقات الصلاة تتضمن:

| الميزة | التفصيل |
|--------|---------|
| **جميع الأوقات** | الفجر، الشروق، الظهر، العصر، المغرب، العشاء |
| **الوقت المتبقي** | عداد تنازلي للصلاة التالية |
| **تحديد الموقع** | اختيار المدينة يدوياً أو تلقائياً |
| **طريقة الحساب** | اختيار طريقة الحساب المناسبة |
| **التنبيهات** | إشعارات قبل وقت الصلاة |

---

### 11. المساجد

خريطة تفاعلية تعرض المساجد القريبة من موقع المستخدم مع:
- اسم المسجد
- المسافة
- إمكانية الملاحة عبر Google Maps

---

### 12. الرسائل والإشعارات

نظام رسائل داخلي يتضمن:

| النوع | الوصف |
|-------|-------|
| **نصائح أسبوعية** | نصائح تربوية أسبوعية مخصصة |
| **تذكيرات** | تذكيرات بالمهام والعبادات |
| **رسائل النظام** | إشعارات من إدارة التطبيق |
| **رسائل المتخصصين** | رسائل من المعلمين أو العلماء المرتبطين |

عند الضغط على إشعار، يُحال المستخدم مباشرة إلى صفحة الرسائل لقراءة المحتوى.

---

### 13. الإعدادات

صفحة الإعدادات مقسمة إلى أقسام مطوية:

| القسم | المحتوى |
|-------|---------|
| **الملف الشخصي** | الاسم، رقم الهوية، رقم الهاتف، معلومات الشريك |
| **اللغة** | العربية، الإنجليزية، الهولندية |
| **الإشعارات** | تفعيل/تعطيل أنواع الإشعارات |
| **النصائح اليومية** | تحديد وقت استلام النصيحة اليومية |
| **الموقع** | تحديد المدينة وطريقة حساب الصلاة |
| **الحساب** | تسجيل الخروج، حذف البيانات |

#### 13.1 الملف الشخصي

يحتوي الملف الشخصي على:
- الاسم الكامل
- رقم الهوية الخاص بالمستخدم
- رقم الهاتف (إلزامي)
- اسم الشريك/الزوجة (إن كان متزوجاً)
- رقم هوية الشريك

---

### 14. استبيان الوالد (Parent Profile)

استبيان شامل يملأه الوالد عند أول استخدام للتطبيق:

| المرحلة | المحتوى |
|---------|---------|
| **المعلومات الأساسية** | الجنس، الحالة الاجتماعية، عدد الأبناء |
| **الصلاة** | المحافظة على الصلوات الخمس، صلاة الفجر خاصة |
| **الحجاب** | حجاب المرأة، أو حجاب زوجة الرجل |
| **طلب العلم** | مصادر العلم الشرعي، الدراسة المنتظمة |
| **التعليم** | نوع تعليم الأبناء (مدرسة، منزلي) |
| **التواصل** | مدى التواصل مع معلمي الأبناء |
| **العلاج** | هل يتابع مع متخصص نفسي |

#### 14.1 شريط التقدم (حسنات الصدق)

يعرض شريط تقدم يشمل **جميع الأسئلة** عبر جميع المراحل (وليس المرحلة الحالية فقط):
- النسبة المئوية بخط كبير وواضح باللون الأحمر
- رسالة تحفيزية باللون الأحمر
- عدد الأسئلة المُجابة من إجمالي الأسئلة

---

### 15. التسجيل والدخول

| الخطوة | التفصيل |
|--------|---------|
| **تسجيل الدخول** | عبر OAuth (Google/Apple) |
| **المعلومات الأساسية** | الاسم، العنوان، رقم الهاتف (إلزامي) |
| **اختيار اللغة** | العربية، الإنجليزية، الهولندية |
| **إضافة الأبناء** | تسجيل بيانات الأبناء |
| **استبيان الوالد** | ملء الاستبيان الشامل |

**رقم الهاتف إلزامي** — إذا لم يُدخله المستخدم عند التسجيل، يُطلب منه عند أول دخول للتطبيق.

---

### 16. لوحة المتخصصين

لوحة خاصة بالمتخصصين (المعلمين، العلماء، الأطباء) تتضمن:

| الميزة | التفصيل |
|--------|---------|
| **التسجيل كمتخصص** | تسجيل البيانات والتخصص |
| **لوحة التحكم** | عرض العائلات المرتبطة |
| **ملف العائلة** | الاطلاع على بيانات العائلة المرتبطة |
| **إنشاء خطة** | إنشاء خطة علاجية/تربوية مخصصة |
| **التواصل** | إرسال رسائل للعائلات |

---

### 17. المقالات والمحتوى

قسم للمقالات والمحتوى التعليمي مقسم إلى:
- مقالات عامة
- محتوى التصفية
- محتوى التزكية
- محتوى التربية

كل مقال يُعرض بنص واضح ومنسق، خالٍ من رموز HTML.

---

### 18. النشرة الإخبارية

نظام نشرة إخبارية يتضمن:
- إرسال نشرات دورية للمشتركين
- محتوى تربوي متجدد
- إمكانية الاشتراك وإلغاء الاشتراك

---

### 19. لوحة الإدارة (Admin)

لوحة تحكم للمسؤولين تتضمن:

| الأداة | الوظيفة |
|--------|---------|
| **إدارة المحتوى** | إضافة وتعديل المقالات والمفاهيم |
| **مولّد المقالات** | إنشاء مقالات بالذكاء الاصطناعي |
| **محرر النشرة** | إنشاء وإرسال النشرات الإخبارية |
| **إدارة المستخدمين** | عرض وإدارة حسابات المستخدمين |

---

### 20. إدارة الهوية

نظام هوية فريد لكل مستخدم:
- رقم هوية فريد يُنشأ تلقائياً
- يُستخدم لربط المستخدمين ببعضهم
- يُستخدم لإضافة المتخصصين
- يمكن مشاركته عبر QR code

## خلاصة

تطبيق "نصيحة" هو منظومة متكاملة للتربية الإسلامية تجمع بين:
1. **المعرفة** — مفاهيم ومقالات تربوية مبنية على المنهج الإسلامي
2. **التطبيق** — نصائح يومية وأسبوعية مع متابعة التنفيذ
3. **الدعم** — مستشار ذكي وشبكة متخصصين
4. **المتابعة** — استبيانات وتقارير تقدم مستمرة
